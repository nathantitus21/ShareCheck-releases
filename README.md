# ShareCheck: download

Find and remove sensitive details before you share text. Everything runs on your device; nothing is uploaded or stored.

**[Download the latest version](../../releases/latest)** (get `sharecheck-0.7.1.zip`)

## Install (Chrome)
1. Download the ZIP and unzip it to a folder. Keep the folder; Chrome loads the extension from it.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and choose the unzipped folder.
4. Click the ShareCheck toolbar icon to open the checker.

## Try it
- **Checker:** click "Try a fictional sample", then "Check text".
- **Selected text:** select text on any page, right-click, "Check selected text with ShareCheck".
- **AI chat drafts:** on ChatGPT, Claude or Gemini, right-click, "Check this draft with ShareCheck".
- **Real-Time Protection (optional, off by default):** open the extension's options page, turn it on, and approve a site. The options page has a Status panel that explains whether it is active.

## Privacy
Text is checked locally and never sent anywhere. Only your settings are saved. ShareCheck matches known patterns only; a clean result never means text is safe.

## Notes
Preview build, not on the Chrome Web Store. It does not update automatically: download the new ZIP to update. Real-Time Protection and the Claude, Gemini and Gmail support have only been tested on local test pages and may need fixes on the live sites. Feedback: open an issue on this repo.
